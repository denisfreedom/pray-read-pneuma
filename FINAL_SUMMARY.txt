📋 JSON FORMAT (What You Need):

{
  "metadata": {
    "lang_short": "en"     ← "en" for English or "lg" for Luganda
  },
  "verses": [
    {
      "book_name": "Genesis",
      "chapter": 1,
      "verse": 1,
      "text": "In the beginning God created the heaven and the earth."
    }
  ]
}
