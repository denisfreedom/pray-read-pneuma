JSON FORMAT
===========

Required Structure:
{
  "metadata": {
    "name": "Bible Version Name",
    "lang": "English" or "Luganda",
    "lang_short": "en" or "lg"
  },
  "verses": [
    {
      "book_name": "Genesis",
      "chapter": 1,
      "verse": 1,
      "text": "Verse text here"
    }
  ]
}

Language Codes:
- "en" or "eng" → English (imports to text_english)
- "lg" or "lug" → Luganda (imports to text_luganda)

ERROR RESOLUTION
================

502 Error or No Import:
1. Check database connection
2. Verify Genesis book exists in system
3. Check book name spelling (case-sensitive)
4. View logs: check_logs or check_console_logs

Invalid JSON:
- Ensure file is valid JSON
- All required fields present
- Check for syntax errors

Book Not Found:
- Verify exact book name matches database
- English: "Genesis", "Exodus", etc.
- Luganda: "Genesisi", "Ekisolo", etc.
