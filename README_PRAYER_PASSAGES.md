GET - Fetch Prayer Passages\n\n**Endpoint**: `GET /api/verse-prayers`\n\n**Parameters**:\n```\nbookId (number, required) - Bible book ID (1=Genesis, 66=Revelation)\nchapter (number, required) - Chapter number\nverseNumber (number, optional) - Verse number\n```\n\n**Example Request**:\n```bash\nGET /api/verse-prayers?bookId=1&chapter=1&verseNumber=4\n```\n\n**Example Response**:\n```json\n[\n  {\n    \"id\": 7,\n    \"book_id\": 1,\n    \"chapter\": 1,\n    \"verse_number\": 4,\n    \"english_prayer\": \"Almighty God, help me to understand Your Word...\",\n    \"luganda_prayer\": \"Katonda Waawey, ntegeeze okukubaganya...\",\n    \"created_at\": \"2026-04-04T06:55:14.747Z\"\n  }\n]\n```\n\n**Status Codes**:\n- `200 OK` - Prayer(s) fetched successfully\n- `400 Bad Request` - Missing required parameters\n- `500 Server Error` - Database error\n\n---\n\n### 2. POST - Save Prayer Passage\n\n**Endpoint**: `POST /api/verse-prayers`\n\n**Request Body**:\n```json\n{\n  \"bookId\": 1,\n  \"chapter\": 1,\n  \"verseNumber\": 4,\n  \"english_prayer\": \"Prayer text...\",\n  \"luganda_prayer\": \"Okukubaganya...\"\n}\n```\n\n**Example Response**:\n```json\n{\n  \"success\": true,\n  \"message\": \"Prayer saved successfully\"\n}\n```\n\n**Status Codes**:\n- `200 OK` - Prayer saved successfully\n- `400 Bad Request` - Invalid parameters\n- `500 Server Error` - Database error\n\n---\n\n### 3. DELETE - Delete Prayer Passage\n\n**Endpoint**: `DELETE /api/verse-prayers`\n\n**Parameters**:\n```\nid (number, required) - Prayer ID to delete\n```\n\n**Example Request**:\n```bash\nDELETE /api/verse-prayers?id=7\n```\n\n**Example Response**:\n```json\n{\n  \"success\": true,\n  \"message\": \"Prayer deleted successfully\"\n}\n```\n\n---\n\n## Database Schema\n\n### verse_prayers Table\n\n```sql\nCREATE TABLE verse_prayers (\n    id INTEGER PRIMARY KEY,\n    book_id INTEGER NOT NULL,\n    chapter INTEGER NOT NULL,\n    verse_number INTEGER NOT NULL,\n    english_prayer TEXT,\n    luganda_prayer TEXT,\n    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,\n    updated_at TIMESTAMP\n);\n```\n\n### Column Descriptions\n\n| Column | Type | Description |\n|--------|------|-------------|\n| `id` | INTEGER | Unique prayer ID (Primary Key) |\n| `book_id` | INTEGER | Bible book ID (1=Genesis ... 66=Revelation) |\n| `chapter` | INTEGER | Chapter number prayer was created |\n| `updated_at` | TIMESTAMP | When prayer was last updated |\n\n### Example Data\n\n```sql\nSELECT * FROM verse_prayers;\n\nid │ book_id │ chapter │ verse_number │ english_prayer Go to Console tab\n   - Look for error messages\n   - Red errors need investigation\n\n4. **Verify verse exists**\n   - Use admin panel \"Find & Edit Verses\" section\n   - Search for your verse\n   -
